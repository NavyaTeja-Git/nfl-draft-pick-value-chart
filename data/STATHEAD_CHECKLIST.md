# Stathead export checklist

Each link is single regular seasons for one draft class, limited to that class's
first five seasons (draft year to draft year + 4, max 2025), sorted by AV.

For each link: open it, hover **Export Data**, click **Get as Excel Workbook**,
and leave the file in Downloads. Then run `py src/step2_stathead.py <YEAR>`.

2012-2017 were collected as 200-row pages (all checked: no duplicates, so nothing
skipped). From 2018 on, each draft round is its own query so it fits on one page;
paged queries can repeat one tied row and skip another.
