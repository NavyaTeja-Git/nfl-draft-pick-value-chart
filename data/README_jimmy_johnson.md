# Jimmy Johnson draft pick value chart

`jimmy_johnson_chart.csv`: points for picks 1-224 of the traditional trade value
chart attributed to Jimmy Johnson (1990s). Transcribed 2026-09-24 from
https://www.drafttek.com/NFL-Trade-Value-Chart.asp, which states it uses the
classic Jimmy Johnson values. Anchors agree with published descriptions
(pick 1 = 3,000, pick 2 = 2,600, pick 3 = 2,200, pick 16 = 1,000,
pick 100 = 100). Used only for comparison in step 7.
